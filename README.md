# ml-anomaly-detection
Machine learning system for detecting anomalous and potentially fraudulent financial transactions.

## Project Goals

- Explore and preprocess transaction data
- Identify relevant features associated with anomalous behaviour
- Train machine learning models for anomaly detection
- Evaluate model performance using appropriate classification metrics
- Analyse false positives and false negatives

## Technologies

- Python
- pandas
- NumPy
- scikit-learn
- Matplotlib
